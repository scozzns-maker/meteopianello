# MeteoPianello

Non ci sono scuse. Meteo del weekend (mattina e pomeriggio) per dieci località delle Marche, con mappa, dettaglio per località, allerte e conto alla rovescia al prossimo aggiornamento.

Pagina: https://scozzns-maker.github.io/meteopianello/

- `index.html`: la pagina.
- `data.js`: previsioni 3B Meteo e allerte Meteoalarm (via AccuWeather), riscritte ogni 6 ore (alle 0:38, 6:38, 12:38 e 18:38) dall'aggiornamento automatico. È l'unico file che cambia.
- `logo.jpg`: il logo.
